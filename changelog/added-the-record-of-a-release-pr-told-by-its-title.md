- A new record states that core's `main` carries the coming version before its tag, raised by a
  pull request before the release with its fragment, that core's release PR raises none while
  its merge tags, and that a release PR is therefore told by its title, `X.Y.Z Release`, or by
  the `release` label, as the organization's conventions check tells it. The review checklist's
  item 13 tells a release PR so in place of the version in `pyproject.toml` changed, and
  ADR-0039 points to the record, which changes its decision 2 in part.
  (ADR-0070, ADR-0039, https://github.com/xippios/sdk-core/issues/561, https://github.com/xippios/sdk-core/issues/566)
